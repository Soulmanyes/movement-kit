Paint Saver

Paint Saver saves your paint per map and paints it again after a map reload or a game restart.

  1. Recording. While you hold the paint key, a HUD script notes where you stand and where you look, every 15 ms, with the paint's colour and size. mk_savepaint keeps the strokes of the map you are on.
  2. Making savestates. At the next game start through the kit, before the game opens, Paint Saver writes each spot of the saved paint into the game's savestate file (savedlocs.txt) as a savestate, in a list of its own named zzpaint_ and the map's name. The game reads that file only when it starts, which is why saved paint comes back only after a restart.
  3. Painting. mk_loadpaint adds that list to the end of your savestates and goes to each of them in turn with paint held, so each one paints where you looked from that spot, in its stroke's colour and size.
  4. Cleaning up. It then deletes those savestates again from the end of the list and restarts the track. Your own savestates stay as they are: if one changes during a load, it stops there and says so, and the leftovers go at the next game start. Your paint colour, size and paint sound settings are put back after a load (the paint sound is off during it).
On: your paint key is bound to Paint Saver's alias, which paints as before and also notes each stroke, and mk_savepaint saves them. Off: your paint key goes back to plain paint and nothing is noted or saved. Paint already saved stays. A change takes effect at the next game start.
With saving on, mk_loadpaint always works. With saving off, it works only while this is on, for paint you saved before. Also from the next game start.

How to use it

  1. Turn on Save paint above, and start the game with the kit's Steam launch option (at the bottom). A key you bind to paint later is picked up at the next game start.
  2. mk_savepaint saves all paint you made on this map since the game started, map reloads included. Save before you quit the game: paint not saved is gone after it.
  3. After the next game start, on that map: mk_loadpaint. Keep the mouse still until the console says paint restored: moving it moves the marks.
  4. mk_clearpaint drops this map's saved paint. What is on screen stays until the map reloads.

For paint that comes back right

  • Don't paint from inside walls, floors or clip brushes (in noclip). Loading paint can't use noclip, so it can't stand where you stood, and that paint comes back in the wrong place.
  • If some paint still comes back off, load it once, restart the game and load it again. Each load notes where each spot ended up, and the next game start corrects the ones that were off. Spots it can't place after a few tries are counted in the console message.
  • Don't paint from inside teleports, boosters or other triggers that move you, or from moving platforms and doors.

On the map you are on

The same as mk_savepaint, mk_loadpaint and mk_clearpaint in the console. They reach the game only when it was started through the kit with Source Yaw installed.
