Third-party software in movement-kit.exe
========================================

Soulmanyes's Movement Kit's own code is CC0 1.0 (see LICENSE). The Windows exe also contains:

- Python 3.13 (the CPython runtime and standard library), with libffi and the Microsoft Visual C++
  runtime (Microsoft Distributable Code). Licence: the Python Software Foundation License, with the
  notices of those parts; the full text is in PYTHON-LICENSE.txt next to this file.

- OpenSSL 3 (libssl and libcrypto, for HTTPS when looking for updates). Licence: Apache License 2.0,
  in OpenSSL-LICENSE.txt next to this file. https://www.openssl.org/

- The PyInstaller bootloader, which unpacks and starts the program. Licence: GNU GPL 2.0 or later
  with the PyInstaller bootloader exception, which allows shipping programs built with it under
  any licence. https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt

- pywebview, which shows the hub's window, and the packages it needs on Windows. The build lists
  each package with its version and licence, and their licence files are in the
  third-party-licenses folder next to this file. https://pywebview.flowrl.com/

- The Microsoft Edge WebView2 SDK files that come with pywebview (the WebView2 loader and its .NET
  wrappers). Licence: the WebView2 SDK's licence from Microsoft.
  https://www.nuget.org/packages/Microsoft.Web.WebView2/
  The window itself is drawn by the WebView2 Runtime that is part of Windows 10 and 11; it isn't
  in the exe.
